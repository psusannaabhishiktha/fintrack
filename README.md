# FinTrack API (skeleton)

This repository contains the FinTrack API domain logic under `src/transactions/` and tests under `tests/`.

Tech stack
- Language: Python 3.10+
- Web framework: FastAPI
- ORM: SQLAlchemy
- Validation: Pydantic
- Tests: pytest + httpx / TestClient

See `ARCHITECTURE.md` for the high-level design and `.github/copilot-instructions.md` for guidance to AI agents working on this repo.
